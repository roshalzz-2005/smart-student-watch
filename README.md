# Smart Student Watch – Smart Wearable for Student Stress Monitoring

## Project Overview
The Smart Student Watch is an IoT-based wearable device designed to monitor students' physiological stress indicators and support better study-time management.

The system uses an ESP32 microcontroller and biomedical sensors to monitor heart rate, skin conductance and skin temperature.

## Objectives
- Monitor students' physiological stress indicators.
- Provide study-time management features.
- Identify elevated stress patterns.
- Suggest relaxation breaks when required.

## Hardware Components
- ESP32 Microcontroller
- MAX30102 Heart Rate Sensor
- GSR Sensor
- Temperature Sensor
- OLED Display
- RTC Module
- Vibration Motor
- Rechargeable Battery

## Key Features
1. **Stress Monitoring:** Monitors heart rate, skin conductance and temperature.
2. **Study Timer:** Supports 25, 45 and 50-minute study sessions.
3. **Stopwatch:** Start, pause and reset functionality.
4. **Time and Date:** Displays real-time information.
5. **Break Reminder:** Provides vibration alerts when elevated stress indicators persist.

## Technologies Used
